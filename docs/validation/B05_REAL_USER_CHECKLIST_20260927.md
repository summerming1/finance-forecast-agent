## 第一次：只有研究目标

1. 记录开始时间。打开 Research Mission，选择受支持的 SPY 日频下一交易日收益模板，填写自己的研究备注。
2. 选择历史输入，先查看快速试跑的预计费用，再选择 Custom 设置 2 轮、每轮 1 个候选、最多 24 fits。创建 Mission，等待实际完成。快速试跑只有一个研究候选，不适合两候选切换验收。
3. 不看助手解释，用自己的话回答：预测的是什么？它是否承诺可交易收益？没有改进是否表示程序失败？
4. 在两个实际完成的研究候选之间切换。查看比较面板参照 ID、真实模型、特征改动、指标和结论；确认切换不增加 fit/attempt 数。如果只有一个候选，原样记录，不补造第二个。
5. 选择一个候选，显式 refit 后下载。记录选择的 candidate ID 和下载包中的 candidate ID 是否一致。
6. 刷新页面，再关闭页面重新打开同一 Mission。检查研究和候选是否仍存在；不点击新研究或重新训练。
7. 看总结与确认预检：它是否明确说明开发证据、费用未知、预检不等于确认授权？展开续接预览，确认这是新 Campaign、继承哪些内容、会新增多少预算；只预览不提交也不应训练。若确实提交，请记录额外 fits，不能当作免费恢复。
8. 记录结束时间、卡住的位置、助手代操作步骤、是否理解结果、这个结果对下一步研究有什么实际用途。
